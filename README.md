# gamearena-landing-page
GameArena is a modern and responsive gaming landing page designed to showcase gaming content, services, and team members through an engaging and visually appealing interface.

## Features

- **Hero Section:** Eye-catching introduction with a gaming-themed design.
- **Latest Games:** Bootstrap carousel showcasing featured games.
- **What We Do:** Highlights gaming services, including:
  - PC & Mobile Game Development
  - AR/VR Design
  - PlayStation 4 Game Development
  - 3D Modeling
- **Game Gallery:** Animated gallery displaying gaming logos.
- **Our Team:** Introduces team members and their roles.
- **Contact Section:** Contact information, social media links, and a message form.
- **Responsive Design:** Layout adapted for different screen sizes.

##  Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome
- Google Fonts

##  Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/gamearena-landing-page.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
